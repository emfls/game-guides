# Playbook: mission-control guide hub
The owner requested an autonomous theme-specific overhaul and publication on existing GitHub Pages. Make the small three-guide collection feel like a useful mission hub, not a generic blog grid. Dark blue command-room frame, crisp blue panels, warm yellow action markers, numbered mission files, original geometric diagrams. No game artwork, logos or screenshots.

The landing page offers direct task navigation for surviving a first night, starting iron production, and diagnosing power. Keep the three existing cards, data attributes, search, game/type filters and resets. The article pages become readable field briefs with on-page navigation, numbered procedures and distinct scope/source callouts. Preserve every guide paragraph, verified source URL, version/provenance caveat, noindex and relative link. No new library, tracking, data or storage.

An artwork-heavy game portal was rejected for rights and inaccurate breadth. A shared blog template was rejected because it does not convey task navigation. The chosen mission hub makes three available guides clear without pretending to cover all games or patches.
